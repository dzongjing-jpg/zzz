# 灵台方寸山 · 帮贡兑换中心

一个可启动的 Web 全栈项目，零第三方 Python 依赖，SQLite 持久化。提供玩家注册登录、QQ绑定码验证、帮贡余额和流水、商品兑换与库存、订单处理、管理员后台。

## 运行步骤

1. 安装 Python 3.10 或以上版本。
2. 在项目目录运行：`python create_admin.py`，输入管理员用户名和至少10位密码。
3. 运行：`python app.py`。
4. 浏览器访问：`http://127.0.0.1:8080`，以管理员身份登录，生成玩家QQ绑定码并私下发放。
5. 玩家自行注册用户名和密码，登录后使用QQ号和一次性绑定码验证，并通过商城兑换商品。

数据文件默认保存在项目目录 `fangcun.db`。可通过环境变量 `DB_PATH`、`HOST`、`PORT`、`COOKIE_SECURE` 覆盖。

## 账户与QQ绑定

- 这是**帮会内部人工验证的QQ号绑定**，不调用腾讯官方接口，**不能技术性证明QQ真实所有权**。管理员必须先通过可靠的其他渠道确认QQ和游戏角色的对应关系。
- 玩家**不需要输入QQ密码**。玩家账号是独立的本站用户名及密码。
- 管理员生成的验证码30分钟过期，仅显示一次，新码会使旧码失效。
- 一个QQ号码最多绑定一个本站账户；账户绑定后暂不开放自行换绑，需要后台人工处理。

## 订单与数据规则

- 兑换时数据库事务内检查帮贡和库存，扣款、扣库存、建订单、帮贡流水同一事务提交。
- 兑换后进入待发放，管理员核对游戏中的发奖情况并点击“确认发放”。
- 拒绝并退款会自动返还帮贡和库存，并记录流水；已发放的订单不能重复退款。
- 管理员修改帮贡必须填原因，留存操作人和余额变动明细。
- 初始有4个**演示商品**，正式上线前请根据帮会规则调整商品；商品名称、成本、库存暂支持新增和上下架，修改现有项目可后续扩展为编辑功能。

## 部署前必须处理

本版本适合内部测试和小规模帮会使用；**不是已经上线的互联网生产环境**。

1. 部署在有HTTPS的可信反向代理（Caddy或Nginx）之后，设置 `COOKIE_SECURE=1`，不要直接将 Python 内置 HTTP 服务公开暴露在互联网。
2. 用防火墙限制服务端口，设置 `HOST=127.0.0.1`，由反向代理向外提供 HTTPS。
3. 对数据库定期备份；建议采用 SQLite 的 backup API 或在停止服务后复制，避免只复制 WAL 主文件。
4. 使用高强度管理员密码，并由可信人员管理绑定码；QQ和角色名属于个人信息，发布隐私告知，避免超范围收集。
5. 发布前建议增加密码找回、管理员二次验证、账号封禁、审计查询、绑定码尝试次数限制、站点级请求限速、现有商品编辑功能、异常告警及安全审计。
6. 若人数和并发持续增长，建议迁移到 PostgreSQL +成熟 Web 框架。

## 健康检查

`GET /health` 输出 `OK`。

## 结构

- `app.py`：HTTP服务器、界面、路由、SQLite数据库结构和业务逻辑。
- `create_admin.py`：交互式创建管理员。
- `test_app.py`：自动化测试核心兑换与退还逻辑。
- `fangcun.db`：本机启动后自动创建，请不要提交真实用户数据给他人。
